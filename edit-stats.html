Why isn’t this “Save to cloud”? Free GitHub Pages only serves files — there is no server to write to. This page is a form that builds stats.json for you. Use Download, then replace the file in your repo (see steps below). Everyone sees updates after you push.

How to publish your download
  1. Open your GitHub repo → stats.json → Edit (pencil).
  2. Paste the JSON from Copy JSON, or upload the downloaded file.
  3. Commit to main. Wait ~1 minute, then refresh the live site.
  4. Optional: paste the same JSON into index.html inside #stats-fallback-data for offline file opens.
